GameVault 2 · Public beta

Download GameVault

GameVault 2 for Windows, Linux and macOS. Bring your own server and play your DRM-free library anywhere.

Prefer the browser? The Web UI is GameVault 2 in your browser, with nothing to install.

Windows

Windows 10 and 11 · x64

Download installer
  • NSIS installer, no administrator rights required
  • SmartScreen: choose More info → Run anyway

Linux

Most distributions · x64

Download AppImageDownload .deb
  • Run chmod +x on the AppImage before the first start
  • Debian/Ubuntu: sudo apt install ./GameVault-*.deb

macOS

Apple Silicon · arm64

Download .dmg
  • Right-click → Open on the first start (Gatekeeper)
  • Intel Macs are not supported by the published build

Early Access is open to everyone. Switch the update channel in the client, no application needed. How to switch channels.

After installation

  1. Start GameVault and add your server. See Connect to a server.
  2. Pick download and installation folders under Settings → Downloads.
  3. Download a game and install it. Details are in Using GameVault.
  4. Running into problems? Check Troubleshooting or the release notes.

GameVault 2 uses a different installation format. Games installed with GameVault 1 have to be downloaded again. See Migrating from GameVault 1 and the full feature comparison.

GameVault 1

GameVault 1 is still available and remains the only client with full GameVault+ support. Install it from the Microsoft Store, or read the GameVault 1 installation guide.

Open Microsoft StoreGameVault 1 documentation

Our binaries are not code-signed. Windows SmartScreen and macOS Gatekeeper may warn on the first start; the installers above come directly from GitHub Releases.
