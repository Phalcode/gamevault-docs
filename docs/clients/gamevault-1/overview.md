# Overview

GameVault 1 is the original .NET desktop app for Windows. It is
feature-complete and receives maintenance fixes only. New features go into
[GameVault 2](../gamevault-2/overview.md).

GameVault 1 is not deprecated. It still works, and it remains the only client
with full [GameVault+](../../gamevault-plus/introduction.md) support.

## When to use it

- You depend on GameVault+ features such as cloud saves, multiple profiles,
  themes or the Steam, Discord and Playnite integrations.
- You want the Microsoft Store distribution with its automatic updates.
- You are on Windows and prefer the most mature client.

## When to use GameVault 2 instead

- You are on Linux or macOS. GameVault 1 is Windows-only.
- You want multiple versions per game, native Linux launching with
  umu-launcher, per-game Wine/Proton prefixes, or gamepad navigation on a Steam
  Deck.
- You want to help test the client that will replace GameVault 1.

The [feature comparison](../feature-parity.md) lists every difference and the
tracking issue for each gap in GameVault 2.
