# Updating

GameVault 1 updates through the Microsoft Store. Every other installation has to
be updated by hand.

## Microsoft Store

The Store build checks for a new version on launch and prompts you to install
it. After the update the app closes; start it again.

## Manual installations

If you compiled the app, extracted it from the `.appxbundle`, or downloaded the
binaries from GitHub, you are responsible for updates. Install a newer build
over the old one; settings and installed games stay in place.

## Update channels

GameVault 1 follows the Microsoft Store release and has no channel picker.
Pre-release builds are described in
[Early Access and update channels](../../early-access.md).
