# Settings

GameVault 1 has a single settings window, opened from the gear icon in the
sidebar. It has one tab per topic: **Application**, **Installation**, **User**,
**Data**, **GameVault+**, **About** and, once unlocked, **Developer**.

## Application

- **Startup**: launch GameVault on computer startup, start in the system tray,
  load the library from the server on startup.
- **Theme**: pick an installed theme, uninstall it, or open the theme folder.
  Community themes are installed from a repository; premium themes need
  [GameVault+](../../gamevault-plus/introduction.md). See [Themes](themes.md).
- **Library**: keep the sorting and filter preferences after a restart.

## Installation

- **Download bandwidth limit**: cap the download speed.
- **Default extraction password**: password for encrypted archives.
- **Download and installation folders**: where the per-game folders are
  created; see [data locations](data.md#games-and-downloads).
- **Auto-extract**: unpack archives right after download.
- **Auto-install**: install portable games automatically.
- **Auto-delete**: remove the install files after a successful installation.

## User

- Edit your user data.
- Switch to another profile or log out of this device or all devices. Multiple
  profiles per installation are a
  [GameVault+](../../gamevault-plus/introduction.md) feature.

## Data

- **Root directories**: add or remove the folders GameVault uses; it creates a
  `GameVault` subfolder in each one.
- **Cache management**: clear the image cache or the offline cache, with the
  current size shown next to each button.
- **Ignored executables**: edit the ignore list that the playtime tracker and
  the executable picker use.
- **Help us improve**: send anonymous usage reports.

## GameVault+

Sign-in and license state for the subscription, plus the feature list. See
[GameVault+](../../gamevault-plus/introduction.md).

## About

Version, update information and third-party licenses.

## Developer

Hidden until developer mode is enabled. Contains diagnostics for bug reports.
