# Overview

GameVault 2 (codename RockWhistle) is the actively developed GameVault client.
It runs on Windows, Linux and macOS, and the same interface is served by the
server as the [Web UI](web-ui.md) for browser access.

:::note Status
GameVault 2 is in public beta. Bugs and missing features are expected. If you
depend on a [GameVault+](../../gamevault-plus/introduction.md) feature, keep
using [GameVault 1](../gamevault-1/overview.md) for now.
:::

## What it covers

- Browse, search, filter and bookmark your server's library.
- Download games, choose between versions, extract and install them.
- Launch games, track playtime and report progress to the server.
- Native Linux support with umu-launcher, per-game Proton prefixes and
  gamepad navigation.
- A built-in updater with stable, early-access and unstable channels.

The [feature comparison](../feature-parity.md) shows what GameVault 2 does not
support yet and links to the tracking issue for each gap.
