## First start

1. Add your server in the login window. See
   [Connect to a server](../../getting-started/connect-to-server.md) for
   sign-in, sign-up and SSO.
2. Open **Settings → Downloads** and pick a download and an installation folder.
   GameVault creates the per-game structure inside them.
3. Download a game from the library.
