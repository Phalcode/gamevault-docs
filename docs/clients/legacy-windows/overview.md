# Legacy Windows Client

The legacy Windows client (GameVault 1) is the original .NET desktop app. It is
feature-complete and receives maintenance fixes only. New features go into
[GameVault 2](../gamevault-2/installation.md).

:::note Status
GameVault 1 is not deprecated. It still works and it remains the only client
with full [GameVault+](../../gamevault-plus/introduction.md) support.
:::

## When to use it

- You depend on GameVault+ features such as cloud saves, multi-profile, themes
  or the Steam, Discord and Playnite integrations.
- You are on Windows and want the most mature client.
- You need the Microsoft Store distribution and its automatic updates.

## When to use GameVault 2 instead

- You are on Linux or macOS. The legacy client is Windows-only; running it
  through Wine or Proton is unsupported.
- You want multiple versions of a game, native Linux launching with
  umu-launcher, or per-game Wine/Proton prefixes.
- You want to help test the client that will replace GameVault 1.
