Server setup

GameVault Server runs on any machine with Docker, or natively on Linux. Pick the guide that matches your host. Every method uses the same image and the same configuration variables.

Before you start

You need a host with at least 2 GB of RAM, a folder for game files and a database. PostgreSQL is recommended for larger libraries; SQLite works for small setups.

Supported methods​

HostGuideNotes
Docker ComposeDocker ComposeRecommended for most Linux hosts and VPS
CapRoverCapRoverManaged Docker host with a web UI
TrueNAS SCALE 24.10 or newerTrueNAS SCALEUses the Docker-compatible app system
UnraidUnraidCommunity Applications template
Synology Container ManagerSynology Container ManagerDSM 7.2 or newer
Linux without DockerNative installationNode.js and PostgreSQL or SQLite

If you have trouble, ask on Discord. Include your host, the method you used and the server logs.

Add more setup guides​

GameVault runs on more systems than we can test. If you set it up on a NAS or a platform that is missing here, a documentation pull request is welcome: gamevault-docs.

What next?​

Once the server is running, open http://<server-ip>:8080 in a browser. The Web UI is GameVault 2 and needs no installation. Disable it with WEB_UI_ENABLED=false if you only want to serve the API.

  1. Configure the server. Review the configuration reference.
  2. Add games. Prepare the file and folder structure, then add your games.
  3. Create the first user. The first registered account is activated automatically and receives the admin role. See user management.
  4. Add metadata. Connect a provider such as IGDB.
  5. Expose the server. For access outside your LAN, use an HTTPS reverse proxy and review Fail2Ban.
