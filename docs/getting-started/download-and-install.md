# Download and install

All desktop builds are published on the [download page](/download) and on
[GitHub Releases](https://github.com/Phalcode/gamevault-frontend/releases).

## Pick your platform

| Platform                 | Guide                                                                       |
| ------------------------ | --------------------------------------------------------------------------- |
| Windows                  | [Installing GameVault 2 on Windows](../clients/gamevault-2/installation.md) |
| Linux (AppImage, `.deb`) | [Installing GameVault 2 on Linux](../clients/gamevault-2/linux.md)          |
| macOS                    | [Installing GameVault 2 on macOS](../clients/gamevault-2/macos.md)          |
| Browser, no installation | [Open the Web UI](../clients/gamevault-2/web-ui.md)                         |
| Windows, Microsoft Store | [Installing GameVault 1 on Windows](../clients/gamevault-1/installation.md) |

Two things are true for every platform:

- The builds are not code-signed, so Windows SmartScreen and macOS Gatekeeper
  may warn you on first start. The platform guides explain how to continue.
- GameVault 2 updates itself through a built-in updater; GameVault 1 updates
  through the Microsoft Store. Manual installs are covered under
  [GameVault 2 updates](../clients/gamevault-2/updating.md) and
  [GameVault 1 updates](../clients/gamevault-1/updating.md).
