Frequently asked questions

Do I need my own server?​

Yes. GameVault is self-hosted: you run the server on your own hardware or a hosted virtual machine, and your clients connect to it. There is no official hosted GameVault service.

If you only want to look around, use the demo server:

URL: demo.gamevau.lt
Username: demo
Password: demodemo

Start with server setup if you want your own instance.

Which client should I use?​

GameVault 2 for Windows, Linux and macOS, or GameVault 1 if you need a GameVault+ feature or the Microsoft Store distribution. The feature comparison has the full matrix.

Is GameVault 2 ready for daily use?​

It is in public beta. The core loop (browse, download, install, launch) works, but some features are missing and bugs are expected. GameVault 1 remains available and feature-complete.

Can I keep games installed with GameVault 1?​

No. GameVault 2 uses a different installation layout, so games have to be downloaded and installed again. Your server data, account and playtime are unaffected. See Migrating from GameVault 1.

Does GameVault run on Linux and macOS?​

Yes, with GameVault 2. Linux packages are .AppImage and .deb; macOS gets an Apple Silicon .dmg. GameVault 1 is Windows-only.

Can I download or launch games from the browser?​

The Web UI can download game files in the browser and hand a download off to an installed GameVault 2 client. A browser cannot start local processes, so automatic extraction, installation, launching and playtime tracking require the desktop app.

Is GameVault free?​

The server and clients are free to use. GameVault is source-available under CC BY-NC-SA 4.0, not OSI open source. An optional GameVault+ subscription adds extras and funds development.

Is GameVault+ available in GameVault 2?​

Not yet; it requires GameVault 1. The feature comparison lists every feature with its tracking issue.

How do I get Early Access builds?​

Early Access is open to everyone, with no application or signup. The steps and channels are described in Early Access and update channels.

How do I update?​

GameVault 2 updates itself through its built-in updater. GameVault 1 updates through the Microsoft Store, or manually if you installed it elsewhere. See GameVault 2 updates and GameVault 1 updates.

How do I hide my user name in screenshots?​

Enable Streamer / OPSEC mode under Settings → Appearance, or press Ctrl+Shift+O.

Where do I report bugs?​

  • Client: gamevault-frontend
  • Server: gamevault-backend
  • Docs: gamevault-docs

For setup problems, check Troubleshooting and Early Access and Update Channels first.
